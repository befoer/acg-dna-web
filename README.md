# 次元属性 - 可视化属性图制作工具

只需输入关键词或导入图片，将抽象兴趣可视化，快速生成专属视觉名片，让热爱清晰可见。

次元属性是一个本地优先的二次元属性图编辑器。把喜欢的角色、动画、游戏、歌手和更多作品整理成会呼吸的兴趣成分图，也为每一份热爱留下一张可反复编辑的赛博吧唧展示柜。

打开 GitHub Pages 网站即可进入编辑器。项目、图片和本地字体保存在当前浏览器中，不需要账号或云端同步。

## 关于次元属性

把零散的兴趣名称、图片和回忆，转化为清晰直观的个人兴趣成分占比图。气泡会随权重自然聚合或下沉碰撞，让画面既有信息，也有属于自己的节奏。随着时间补充作品、调整权重、替换图片，动态更新这份数字身份；支持本地项目、自动保存、撤销重做、项目文件和高清 PNG 导出，让每一次整理都能被珍藏。

通过角色、动画、游戏和歌手搜索，或直接导入本地图片，为每一个标签找到合适的视觉表达。资料卡、模板、装饰、字体和画布外观可自由组合，让属性图成为独特的视觉名片。

次元属性不提供账号、公开社区、云端项目库或相似度计算。在线图片搜索直连 Bangumi 官方 API，选中的图片会下载到浏览器本地后再用于编辑。

## 本地开发与部署

安装 Node.js 24 LTS 后运行 `npm ci`、`npm run dev`。生产构建使用 `npm run build`，本地预览使用 `npm run preview`。

在 GitHub 仓库的 Settings → Pages 中选择 GitHub Actions。推送到 `main` 后，部署流程自动检查、构建并发布编辑器，并根据 Pages 配置设置仓库子路径。无需设置自定义域名或 CNAME。

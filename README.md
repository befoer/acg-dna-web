# ACG DNA Web

ACG DNA Web 是一个无需账号、无需自建服务器的属性图创作工具。所有项目数据默认保存在用户自己的浏览器中。

当前状态：核心 MVP 已建立本地编辑与可靠保存闭环。当前版本支持三级属性数据、全局标签样式、内置/本地字体、按 APP 创作页复刻的本地资料与装饰板块、确定性基础聚合/重力碰撞布局、PC 画布完整适应与缩放、Canvas 实时预览、节点与装饰图片、三款本地模板、可调整的标签范围、多项目 IndexedDB 自动保存与恢复、撤销重做、统一装饰图层排序、带图片的项目文件导入导出，以及 PNG 导出；在线搜索按后续阶段推进。

## 核心 MVP

- 创建、打开、复制和删除本地属性图项目
- 编辑分类、属性和子属性的名称、数值、图片、显隐状态与同级顺序；分类和属性列表可折叠，添加前可命名，属性与子属性支持最多 50 项批量添加
- 导入或导出纯文本三级结构：支持 APP 树形文字、简明中文层级格式、追加/替换、实时数量预览、剪贴板和 TXT 文件
- 后续通过 AniList 在线搜索可导出的角色/作品图片；Bangumi 中文词典延期到更后阶段
- 在画布中实时预览属性气泡图
- 提供基础聚合与重力碰撞布局、三款本地模板、标签范围、全局标签样式和分类独立外观；全局“分类显示”可在保留一级分类容器的多层级模式与移除一级分类、让二三级标签独立排布的单层级模式间切换
- 默认使用系统黑体，并提供按需加载的资源圆体 Bold、阿里妈妈方圆体和用户本地字体
- 提供 APP 同款本地资料板块：5 个资料子模板、本地头像、昵称、性别、标签、模板文本块和可拖动的自定义文字；不连接个人账号
- 提供 APP 装饰素材与本地图片：日记装饰、FOX、hosi、喵铺、PP、自定义棋盘/圆点/网格图案、最多 20 个可在画布移动和四角缩放的自定义矩形，以及最多 20 张可在画布直接移动、缩放和旋转的自由本地图片；移动端支持双指组合手势
- 属性图、预设素材、图案、矩形、本地图片和自定义文字共用可拖拽排序的统一图层；拖动手柄也支持上下方向键排序。画布点击与图层列表选择同步，选中的矩形、本地图片和自定义文字可用方向键逐像素微调，预览和 PNG 使用同一前后顺序
- 外观面板内部按“装饰 / 图层 / 画布”分段，移动端主导航仍保持模板、数据、资料、外观四项；图层开关会同时识别元素自身显隐，选中图片或矩形后可快速进入参数区
- 标签范围已并入共享外观面板，调整框默认隐藏并由画布分段中的按钮显式开启；开启后可直接拖动整体、四角和边框调整范围，PC 与移动端统一使用模板、数据、资料、外观四个入口
- 撤销、重做和自动保存
- 导出 PNG
- 导入、导出 ACG DNA Web 自有项目文件
- 移动端尽量延续现有 APP，PC 端使用共享组件的简化工作区

详细边界见 docs/MVP_SCOPE.md。

## 不包含

- 登录、注册、QQ 登录或任何账号体系
- 云端发布、用户主页、关注、收藏和通知
- 公开图社区、相似度计算或服务器同步
- 从旧 Android 应用导入用户项目数据
- 自建图片代理和第三方数据批量采集

## 开发

需要 Node.js 20.19+、22.12+ 或 24+。在仓库根目录执行：

```bash
npm install
npm start
```

`npm start` 会启动 Vite 并自动打开正确的本地网址。不要直接双击仓库根目录的 `index.html`，它是需要 Vite 转译的源码入口。

提交前可运行完整本地检查：

```bash
npm run format:check
npm run lint
npm run typecheck
npm test
npm run build
```

项目和本地图片 Blob 会按项目隔离保存在浏览器 IndexedDB，支持新建、切换、复制、重命名和删除；项目面板仅显示当前来源的浏览器存储已用空间，保存失败状态可直接点击重试。项目恢复后会自动按文档内容与图片 SHA-256 指纹清理完全相同的异常副本，优先保留当前项目，否则保留最近保存的一份；用户主动复制后产生的“副本”名称不同，不会被清理。每次成功保存都会移除当前项目不再引用的旧图片 Blob，删除项目也会同步删除其图片。节点图片、资料头像和装饰图片只保存非破坏式调整参数，不反复压缩原始 Blob；Canvas 预览与 PNG 导出共用同一绘制结果。装饰图片及其显隐、透明度、变换和图层顺序均进入自动保存、撤销重做及带图片的 `.acgdna.json` 项目文件。编辑器支持顶部按钮以及 `Ctrl/Cmd+Z`、`Ctrl/Cmd+Shift+Z`、`Ctrl/Cmd+Y` 撤销重做。

仓库包含 GitHub Actions 持续检查：推送到 `main` 或更新 Pull Request 时，在干净的 Node.js 22 环境运行依赖安装、格式检查、TypeScript、ESLint、测试和生产构建。工作流只读仓库内容，不自动部署或提交代码。

两套内置中文字体只在用户选中时加载，PNG 导出会等待所选字体就绪。用户选择的 TTF、OTF、WOFF 或 WOFF2 字体只保存在当前浏览器的独立 IndexedDB 字体库，不上传，也不嵌入 `.acgdna.json`；换浏览器或换设备后需要重新选择同一字体文件。

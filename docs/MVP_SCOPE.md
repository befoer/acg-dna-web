# 核心 MVP 范围

## 已确认决策

- 仓库名称：acg-dna-web
- 产品形态：无账号、无自建服务器的纯前端编辑器
- 许可证：MPL-2.0
- 不导入旧 Android 用户项目数据
- 当前 Android 工程仅作为视觉和逻辑迁移参考
- 移动端优先并尽量延续 APP；PC 第一版使用共享组件的简化响应式工作区
- 第一版允许在线搜索图片；Bangumi 通过作者控制的受限无状态网关访问，AniList 作为浏览器直连备用，不建设账号、项目同步或图片图库服务器

## 产品目标

用户打开网页后，不登录即可创建属性图、编辑数据、实时预览、自动保存，并导出可以分享的高清图片。

## 当前阶段（2026-07-23）

- 里程碑 1–3 已完成可运行闭环：本地编辑、可靠保存、项目文件、在线图片搜索和 Blob 本地化均已落地。
- 里程碑 4 的模板、APP 资料/装饰板块和 PC/移动共享工作区已实现，当前重点是界面微调、真机手势、响应式和可访问性验收。
- 重力布局已完成多项目种子、极端权重、子标签填充、顶层无重叠和顶部标题碰撞回归；后续调整应继续补测试，避免重新出现串列、悬空或交叠。
- 本阶段不新增账号、云同步、公共图库、批量装饰导入或新的服务端能力。

## 实施里程碑

核心 MVP 按以下顺序完成；在线搜索仍属于第一版发布范围，但不阻塞最早的本地编辑闭环：

1. 编辑闭环：精简数据模型、单一基础布局、Canvas 预览、本地图片和 PNG 导出。
2. 可靠保存：IndexedDB、撤销重做、第二种布局以及 Web 项目文件的导入导出。
3. 在线搜索：Bangumi 主搜索、AniList 备用、Blob 本地化、来源记录、缓存和限流处理；Bangumi 中文词典延期到后续版本。
4. 视觉完善：APP 同款本地资料板块、首批固定模板、移动/PC 响应式与可访问性验收。

每个里程碑都应保持可运行、可测试；不要同时铺开四个阶段。

## MVP 功能

### 本地项目

- 创建空白项目
- 打开、重命名、复制和删除项目
- IndexedDB 自动保存
- 显示保存状态和最近保存时间
- 导入、导出仅面向 Web 版的新项目格式

### 属性数据

- 支持分类、属性、子属性三级结构
- 支持全局分类显示开关，在一级分类容器模式和二三级扁平模式间切换
- 添加、删除、重命名、排序和显隐
- 使用滑块或数值输入调整权重
- 从本地选择图片并裁切
- 使用 Bangumi 搜索角色、动画、游戏和歌手图片；角色与动画可使用 AniList 备用搜索，角色也可按作品查找
- 在线选中的图片立即转为 Blob 并保存到 IndexedDB，不把第三方热链作为项目唯一数据源

### 画布与布局

- Canvas 2D 实时预览
- 迁移确定性布局种子，保证同一项目结果稳定
- 提供基础聚合和重力碰撞布局；重力模式支持顶层贴底、零间隙圆碰撞、子标签父圆约束和容器顶部标题碰撞
- 支持缩放、适配视图和基础节点选择
- 点击属性圈可直接调整图片、添加子标签或删除标签
- 支持背景色、画布比例和基础描边设置
- 外观面板支持 APP 作者装饰素材、基础背景图案、自定义矩形和标签范围

### 视觉标题卡

资料板块属于作品构图，不属于账号体系，因此按 APP 创作页保留：

- 可爱日记与工业风的 5 个资料子模板
- 本地头像以及头像/昵称独立显隐
- 昵称、男/女/无性别、0–4 个标签
- 模板文本块
- 可在画布拖动的自定义文字，以及字体、字号、字重、旋转、宽度、颜色和描边设置；文字可进入统一图层排序和显隐

MVP 不包含：从账号自动导入资料、“我的主页”头像来源、社交链接、账号字段或服务器同步。

### 编辑体验

- 撤销与重做
- 自动保存
- 桌面端键盘快捷键
- 手机端至少 44 x 44 像素触控目标
- 手机端使用底部抽屉
- 外观抽屉内部使用装饰、图层、画布三个分段，避免把全部参数堆叠成长列表
- PC 第一版为左侧工具栏、单个固定功能面板和中央画布；右侧属性检查器延后
- 尊重 prefers-reduced-motion

### 导出

- 导出 PNG
- 导出尺寸与屏幕显示解耦
- 本地图片和同源素材可直接导出
- 在线图片必须先通过 CORS 校验并转为本地 Blob，避免 Canvas 跨域污染

## MVP 暂不包含

- 通用模板编辑器；现有固定模板可按实现进度接入
- 分享链接、二维码和云同步
- PWA 离线安装
- 多人协作
- 公开图库和使用统计

## 验收标准

1. 网页已经加载后，即使断网仍能继续编辑本地项目；本阶段不要求断网冷启动或刷新网页。
2. 应用只允许为用户主动发起的公开图片/元数据搜索联网，不发送账号、项目内容或相似度数据。
3. 刷新浏览器后项目仍存在。
4. 撤销和重做不会破坏数据层级。
5. 同一项目和布局种子产生稳定结果。
6. 可以导出清晰的 PNG，且本地图片正常显示。
7. 在 375、768、1024 和 1440 像素宽度下无横向溢出。
8. 基础编辑功能可使用键盘完成，并具有可见焦点状态。
9. 在线图片搜索具有防抖、取消旧请求、缓存和 429 限流处理。
10. 用户选择的在线图片在刷新后仍能显示，并可以正常导出 PNG。

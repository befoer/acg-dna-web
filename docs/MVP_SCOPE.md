# 核心 MVP 范围

## 已确认决策

- 仓库名称：acg-dna-web
- 产品形态：无账号、无自建服务器的纯前端编辑器
- 许可证：MPL-2.0
- 不导入旧 Android 用户项目数据
- 当前 Android 工程仅作为视觉和逻辑迁移参考
- 移动端优先并尽量延续 APP；PC 第一版使用共享组件的简化响应式工作区
- 第一版允许直接调用公开 API 在线搜索图片，不建设自有服务器

## 产品目标

用户打开网页后，不登录即可创建属性图、编辑数据、实时预览、自动保存，并导出可以分享的高清图片。

## 实施里程碑

核心 MVP 按以下顺序完成；在线搜索仍属于第一版发布范围，但不阻塞最早的本地编辑闭环：

1. 编辑闭环：精简数据模型、单一基础布局、Canvas 预览、本地图片和 PNG 导出。
2. 可靠保存：IndexedDB、撤销重做、第二种布局以及 Web 项目文件的导入导出。
3. 在线搜索：AniList 图片、Blob 本地化、缓存和限流处理；Bangumi 中文词典延期到后续版本。
4. 视觉完善：APP 同款本地资料板块、首批固定模板、移动/PC 响应式与可访问性验收。

每个里程碑都应保持可运行、可测试；不要同时铺开四个阶段。

## MVP 功能

### 本地项目

- 创建空白项目
- 打开、重命名、复制和删除项目
- IndexedDB 自动保存
- 显示保存状态和最近保存时间
- 导入、导出仅面向 Web 版的新项目格式

### 属性数据

- 支持分类、属性、子属性三级结构
- 添加、删除、重命名、排序和显隐
- 使用滑块或数值输入调整权重
- 从本地选择图片并裁切
- 使用 AniList 直接搜索角色/作品图片
- 在线选中的图片立即转为 Blob 并保存到 IndexedDB，不把第三方热链作为项目唯一数据源

### 画布与布局

- Canvas 2D 实时预览
- 迁移确定性布局种子，保证同一项目结果稳定
- 至少提供基础聚合布局和分类分组布局
- 支持缩放、适配视图和基础节点选择
- 支持背景色、画布比例和基础描边设置

### 视觉标题卡

资料板块属于作品构图，不属于账号体系，因此按 APP 创作页保留：

- 可爱日记与工业风的 5 个资料子模板
- 本地头像以及头像/昵称独立显隐
- 昵称、男/女/无性别、0–4 个标签
- 模板文本块
- 可在画布拖动的自定义文字，以及字体、字号、字重、圆度、旋转、宽度、颜色和描边设置

MVP 不包含：从账号自动导入资料、“我的主页”头像来源、社交链接、账号字段或服务器同步。

### 编辑体验

- 撤销与重做
- 自动保存
- 桌面端键盘快捷键
- 手机端至少 44 x 44 像素触控目标
- 手机端使用底部抽屉
- PC 第一版为左侧工具栏、单个固定功能面板和中央画布；右侧属性检查器延后
- 尊重 prefers-reduced-motion

### 导出

- 导出 PNG
- 导出尺寸与屏幕显示解耦
- 本地图片和同源素材可直接导出
- 在线图片必须先通过 CORS 校验并转为本地 Blob，避免 Canvas 跨域污染

## MVP 暂不包含

- 完整装饰图层系统
- 自定义边框、背景图案和自由文字图层
- 通用模板编辑器；现有固定模板可按实现进度接入
- 分享链接、二维码和云同步
- PWA 离线安装
- 多人协作
- 公开图库和使用统计

## 验收标准

1. 网页已经加载后，即使断网仍能继续编辑本地项目；本阶段不要求断网冷启动或刷新网页。
2. 应用只允许为用户主动发起的公开图片/元数据搜索联网，不发送账号、项目内容或相似度数据。
3. 刷新浏览器后项目仍存在。
4. 撤销和重做不会破坏数据层级。
5. 同一项目和布局种子产生稳定结果。
6. 可以导出清晰的 PNG，且本地图片正常显示。
7. 在 375、768、1024 和 1440 像素宽度下无横向溢出。
8. 基础编辑功能可使用键盘完成，并具有可见焦点状态。
9. 在线图片搜索具有防抖、取消旧请求、缓存和 429 限流处理。
10. 用户选择的在线图片在刷新后仍能显示，并可以正常导出 PNG。

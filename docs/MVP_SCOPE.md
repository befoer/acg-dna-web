# 核心 MVP 范围

## 已确认决策

- 仓库名称：acg-dna-web
- 产品形态：无账号、无服务器的纯前端编辑器
- 许可证：MPL-2.0
- 不导入旧 Android 属性图数据
- 当前 Android 工程仅作为视觉和逻辑迁移参考

## 产品目标

用户打开网页后，不登录即可创建属性图、编辑数据、实时预览、自动保存，并导出可以分享的高清图片。

## MVP 功能

### 本地项目

- 创建空白项目
- 打开、重命名、复制和删除项目
- IndexedDB 自动保存
- 显示保存状态和最近保存时间
- 导入、导出仅面向 Web 版的新项目格式

### 属性数据

- 支持分类、属性、子属性三级结构
- 添加、删除、重命名、排序和显隐
- 使用滑块或数值输入调整权重
- 从本地选择图片并裁切
- 不接入远程标签、角色或图片搜索

### 画布与布局

- Canvas 2D 实时预览
- 迁移确定性布局种子，保证同一项目结果稳定
- 至少提供基础聚合布局和分类分组布局
- 支持缩放、适配视图和基础节点选择
- 支持背景色、画布比例和基础描边设置

### 视觉标题卡

视觉标题卡属于作品构图，不属于账号体系，因此保留精简版：

- 本地头像
- 昵称
- 显示或隐藏
- 少量预设位置与样式

MVP 不包含：从账号导入资料、性别、社交链接、复杂标签、多个资料子模板、自由文字图层和复杂命中检测。

### 编辑体验

- 撤销与重做
- 自动保存
- 桌面端键盘快捷键
- 手机端至少 44 x 44 像素触控目标
- 桌面端使用侧栏，手机端使用底部抽屉
- 尊重 prefers-reduced-motion

### 导出

- 导出 PNG
- 导出尺寸与屏幕显示解耦
- 项目图片全部来自本地文件或已审核的同源素材，避免 Canvas 跨域污染

## MVP 暂不包含

- 完整装饰图层系统
- 自定义边框、背景图案和自由文字图层
- Cute Pink、Endfield 等尚未完成授权确认的模板
- 分享链接、二维码和云同步
- PWA 离线安装
- 多人协作
- 公开图库和使用统计

## 验收标准

1. 断网后仍能打开已经加载过的开发页面并编辑本地项目；正式 PWA 缓存不属于本阶段。
2. 应用运行期间不发送账号、项目内容或相似度相关网络请求。
3. 刷新浏览器后项目仍存在。
4. 撤销和重做不会破坏数据层级。
5. 同一项目和布局种子产生稳定结果。
6. 可以导出清晰的 PNG，且本地图片正常显示。
7. 在 375、768、1024 和 1440 像素宽度下无横向溢出。
8. 基础编辑功能可使用键盘完成，并具有可见焦点状态。

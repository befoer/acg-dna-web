# 产品介绍与使用边界

## 把热爱变得看得见

次元属性将角色、动画、游戏、歌手和其他兴趣，组织为一张可自由编辑的可视化属性图。标签的大小表达偏好程度，图片、文字、模板与装饰共同组成个人化的次元名片。

它适合整理长期喜欢的作品，也适合为一段时间的心动做一张成分表。内容可以随时增减，权重可以反复调整，画面会跟着兴趣一起生长。

## 自由组合的个人展示柜

编辑器提供多层级标签、重力碰撞布局、画布模板、资料卡、装饰、字体和图层。无论是简洁的兴趣比例图，还是包含头像、昵称和自定义文字的视觉海报，都可以在同一张画布中完成。

你可以输入关键词寻找角色、动画、游戏或歌手图片，也可以使用自己的本地图片。完成后导出 PNG，或保存为项目文件，之后继续编辑。

## 内容留在自己的设备

不需要注册账号。项目、用户图片和本地字体默认保存在当前浏览器；编辑器不建立个人主页、公开作品库或云端同步。

在线图片搜索仅在用户主动发起时访问 Bangumi 与 AniList 的公开服务。选中的图片会保存到本地浏览器，用于画布预览和导出；项目不会长期依赖第三方图片热链。

## 使用边界

次元属性不提供登录、社区、关注、通知、付费服务、多人协作、公开图库或相似度计算。它是一间留给个人兴趣表达与整理的本地创作工具。

用户应确认输入的文字、上传的文件和选择的图片具有合法使用权。在线图片的来源、服务边界与版权责任见 [在线图片与版权说明](ONLINE_IMAGE_SEARCH.md)。
